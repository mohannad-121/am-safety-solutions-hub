# Core Web Vitals and Mobile SEO Report

Date: 14 November 2026

The site uses one responsive URL set with a viewport declaration and no mobile subdomain. Production mobile QA covers 320 through 768 pixels and compares desktop/mobile title, description, canonical, H1, schema, links and alt coverage.

PageSpeed Insights is connected through the server-only Edge Function and remains disabled until `PAGESPEED_API_KEY` is configured. LCP, CLS and INP are not claimed before post-deployment measurements. The main bundle remains a performance follow-up area; route-level lazy loading is active.
